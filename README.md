# ALU Machine Learning

Exercises and projects for learning the mathematics and programming foundations used in machine learning.

## Repository Structure

- `maths/plotting/` contains introductory Matplotlib plotting exercises.

## Requirements

- Python 3
- NumPy
- Matplotlib

Install the Python dependencies with:

```bash
pip install numpy matplotlib
```

## Running an Exercise

Change into the relevant directory and run a script with Python:

```bash
cd maths/plotting
python 0-line.py
```

Each script opens its chart in a Matplotlib window.
