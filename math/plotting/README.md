# Plotting Exercises

Introductory Matplotlib exercises using NumPy-generated data.

## Exercises

| File | Description |
| --- | --- |
| `0-line.py` | Plots a cubic line graph. |
| `1-scatter.py` | Plots height and weight as a scatter plot. |
| `2-change_scale.py` | Plots C-14 exponential decay with a logarithmic y-axis. |
| `3-two.py` | Compares C-14 and Ra-226 radioactive decay. |
| `4-frequency.py` | Displays student grades in a histogram. |
| `5-all_in_one.py` | Combines the previous plots into one figure. |
| `6-bars.py` | Displays fruit quantities in a stacked bar chart. |

## Requirements

- Python 3
- NumPy
- Matplotlib

Install the dependencies with:

```bash
pip install numpy matplotlib
```

Run an exercise from this directory with:

```bash
python 0-line.py
```

Each script opens its generated chart in a Matplotlib window.
