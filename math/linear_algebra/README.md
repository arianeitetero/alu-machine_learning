# Linear Algebra

Solutions for the ALU Machine Learning linear algebra project.

The exercises cover Python list slicing, matrix shapes, transposes, element-wise operations, concatenation, matrix multiplication, and equivalent NumPy operations.

## Requirements

- Python 3
- NumPy

Install NumPy with:

```bash
pip install numpy
```

Run an exercise from this directory with:

```bash
python3 0-slice_me_up.py
```
